# GitHub Organization Description

## Organization Display Name
**Grid Platform**

## Organization Description
The self-hosted infrastructure orchestration platform — for enterprises that want to deploy and manage infrastructure with control that stays theirs.

## Organization Website
https://gridplatform.org

## Organization Location
Global (Open Source Community)

## Organization Bio
Grid Platform is a self-hosted infrastructure orchestration platform. Enterprises use it to deploy and run cloud infrastructure while keeping ownership of how things roll out, who can change them, and where access lives — without handing that control to another vendor.

## Key Focus Areas
- **Self-hosted** — you run Grid on your own machines
- **Enterprise control** — deploy and manage infrastructure without vendor lock-in
- **Clear history** — review and apply changes with a trail your team can follow
- **Your settings** — keep desired-state in a repository you own
- **Docs-first install** — [grid-docs](https://github.com/gridplatform/grid-docs)

## Public product repositories
- **grid-core** — Runs Grid + install packaging
- **grid-ui** — Browser console
- **grid-cli** — Command-line tool
- **grid-terraform** — Ready-made cloud building blocks
- **grid-config** — Example desired-state only (create your own for real use)
- **grid-docs** — Guides
